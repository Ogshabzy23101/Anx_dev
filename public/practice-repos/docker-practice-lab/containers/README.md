# Containers Labs

Purpose: practice `docker ps`, `logs`, `inspect`, `exec`, restart workflows, and container evidence capture.

Sample tasks:

1. List running containers.
2. List exited containers.
3. Inspect `inspect-app.json`.
4. Extract the app container IP.
5. Read the simulated debug session.
6. Write a command to exec into a container.
7. Identify the published ports.
8. Save logs before restart.

Suggested commands: `docker ps`, `docker logs`, `docker inspect`, `docker exec`, `docker restart`, `docker cp`.

Expected outcome: you should be able to inspect and debug containers without guessing.
