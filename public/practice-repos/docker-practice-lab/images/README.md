# Images Labs

Purpose: practice image listing, tagging, history, registry naming, Docker Hub pushes, and CI image promotion.

Sample tasks:

1. List local images.
2. Tag `practice/simple-app` for a registry.
3. Tag an image for Docker Hub.
4. Compare mutable tags with pinned versions.
5. Read `registry-tags.txt`.
6. Explain the problem with `latest`.
7. Draft a rollback tag command.
8. Build a commit-tagged image for CI.

Suggested commands: `docker images`, `docker tag`, `docker pull`, `docker push`, `docker history`.

Expected outcome: you should understand how images move from local builds to registries.
