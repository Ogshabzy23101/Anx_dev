# Compose Labs

Purpose: practice multi-service app stacks, service dependencies, env files, networks, volumes, and Compose troubleshooting.

Sample tasks:

1. Render `compose-stack.yml` with `docker compose config`.
2. Start the full stack.
3. Find the backend service port mapping.
4. Explain the broken dependency in `broken-compose.yml`.
5. Identify the network mismatch.
6. Locate the missing env var.
7. Find the named volume.
8. Read the healthcheck definition.
9. Diagnose the bind mount issue.
10. Restart only the backend service.

Suggested commands: `docker compose config`, `docker compose up`, `docker compose ps`, `docker compose logs`, `docker compose restart`.

Expected outcome: you should be able to operate and debug a local Compose stack.
