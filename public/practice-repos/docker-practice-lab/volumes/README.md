# Volumes Labs

Purpose: practice named volumes, bind mounts, backups, restores, and ownership issues.

Sample tasks:

1. Create a named volume.
2. Inspect a named volume.
3. Find the volume in `compose-stack.yml`.
4. Explain the bind mount issue.
5. Back up a named volume with `tar`.
6. Restore a volume into a new volume.
7. Run a container with a bind mount.
8. Run a bind mount with your user ID.

Suggested commands: `docker volume create`, `docker volume ls`, `docker volume inspect`, `docker run -v`, `tar`.

Expected outcome: you should understand the difference between named volumes and bind mounts.
