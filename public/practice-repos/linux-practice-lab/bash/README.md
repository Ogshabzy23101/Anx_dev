# Bash Labs

Purpose: practice Bash health checks, variables, conditionals, and report generation.

Sample tasks:

1. Run `bash -n health-report.sh`.
2. Find every variable reference in the script.
3. Redirect script output to `health-report.txt`.
4. Add a timestamp to the report.
5. Loop over log files and count errors.
6. Write an `if` statement around a curl health check.
7. Use an environment variable for the log path.
8. Add a trap for cleanup in a copied script.

Suggested commands: `bash`, `grep`, `chmod`, `date`, `for`, `if`, `trap`.

Expected outcome: you should be able to write small repeatable operational scripts.
