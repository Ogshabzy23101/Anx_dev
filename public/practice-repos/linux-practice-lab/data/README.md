# Data Labs

Purpose: practice text processing with CSV, lists, and small report files.

Files:

- `users.csv` - user accounts and team metadata
- `orders.csv` - order states and amounts
- `errors.txt` - extracted application errors
- `servers.txt` - server inventory lines

Sample tasks:

1. Print all production servers.
2. Count failed orders.
3. Extract users in the platform team.
4. Sum order amounts with `awk`.
5. Find disabled users.
6. Sort servers by environment.
7. Extract only hostnames.
8. Count unique error codes.
9. Save failed orders to a new file.
10. Join simple reports by environment manually.

Suggested commands: `cut`, `awk`, `grep`, `sort`, `uniq`, `wc`, `column`.

Expected outcome: you should be comfortable turning flat files into quick operational reports.
