# Archives Labs

Purpose: practice `tar`, `gzip`, archive listing, extraction, and integrity checks.

Files:

- `backup.tar.gz` - generated sample backup archive
- `logs.tar.gz` - generated sample logs archive

Sample tasks:

1. List archive contents without extracting.
2. Extract an archive into `/tmp/linux-practice-restore`.
3. Verify gzip integrity.
4. Create a new archive from `configs/`.
5. Compress a single log file.
6. Extract only one file from an archive.
7. Compare extracted config files.
8. Find archive sizes.
9. Create a timestamped archive name.
10. Remove a test extraction directory safely.

Suggested commands: `tar`, `gzip`, `du`, `ls`, `mkdir`, `rm`.

Expected outcome: you should be able to package, inspect, and restore Linux files safely.
