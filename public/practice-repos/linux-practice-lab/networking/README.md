# Networking Labs

Purpose: practice endpoint inspection, connectivity checks, and port troubleshooting.

Sample tasks:

1. Print every HTTP endpoint.
2. Extract hostnames from `endpoints.txt`.
3. Identify database port entries.
4. Test the health URL with `curl`.
5. Use `nc -vz` syntax for `db.internal:5432`.
6. Sort endpoints alphabetically.
7. Count local endpoints.
8. Build a command list for manual health checks.

Suggested commands: `grep`, `awk`, `cut`, `sort`, `curl`, `nc`, `xargs`.

Expected outcome: you should be able to translate endpoint lists into useful checks.
