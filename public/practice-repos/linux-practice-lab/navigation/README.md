# Navigation Labs

Purpose: practice moving through nested project directories and locating files quickly.

Sample tasks:

1. Print the current directory.
2. Move into `projects/app`.
3. List all files two levels deep.
4. Find every `.conf` file.
5. Locate shell scripts below the app tree.
6. Print the absolute path of `current.log`.
7. Use `find` to list only directories.
8. Return to the repository root safely.

Suggested commands: `pwd`, `cd`, `ls`, `find`, `tree`.

Expected outcome: you should be able to orient yourself in an unfamiliar project tree.
