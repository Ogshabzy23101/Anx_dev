# Files Labs

Purpose: practice inspecting, comparing, copying, and safely modifying files.

Sample tasks:

1. Show the first lines of `app.conf`.
2. Compare `app.conf` with `app.conf.prev`.
3. Save a unified diff to `config.diff`.
4. Find TODO entries in `release-notes.txt`.
5. Copy `app.conf` before editing.
6. Replace `DEBUG=true` in a copied file.
7. Count release note lines.
8. Show file sizes in human-readable format.

Suggested commands: `cat`, `head`, `tail`, `cp`, `diff`, `grep`, `sed`, `wc`, `ls`.

Expected outcome: you should be able to inspect and protect files before changing them.
